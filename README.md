# Wahrheit oder Pflicht (Truth or Dare)

A browser-based "Truth or Dare" party game written in German, built with HTML and JavaScript.

## Features

- Party game for groups in the browser
- Game logic in `app.js`, UI in `index.html`

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Higer23/wahrheit-oder-pflicht.git
   cd wahrheit-oder-pflicht
   ```
2. Open `index.html` in a modern browser.

## Project Structure
